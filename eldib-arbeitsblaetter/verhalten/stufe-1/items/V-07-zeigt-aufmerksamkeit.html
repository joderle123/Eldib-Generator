V-07

Zeigt Aufmerksamkeit für Bezugsperson

Verhalten • Stufe I • Bindung & Orientierung

📖 Zielbeschreibung

Das Kind richtet seine Aufmerksamkeit gezielt auf vertraute Bezugspersonen. Es erkennt diese, unterscheidet sie von Fremden und zeigt besonderes Interesse an ihrer Anwesenheit. Diese selektive Aufmerksamkeit ist ein wichtiger Meilenstein der Bindungsentwicklung.

Entwicklungsbedeutung: Die bevorzugte Orientierung auf Bezugspersonen zeigt, dass das Kind beginnt, sichere Bindungen aufzubauen. Es lernt, seine Umwelt zu unterscheiden und findet in der Bezugsperson einen "sicheren Hafen".

🎮 Praktische Übungen

1 Gesicht-zu-Gesicht-Spiele

Fördern Sie die gegenseitige Aufmerksamkeit durch nahes Interagieren.

  1. Positionieren Sie sich im Sichtfeld des Kindes (ca. 25-30 cm Abstand)
  2. Warten Sie, bis das Kind Sie anschaut
  3. Reagieren Sie mit Lächeln und Mimik
  4. Sprechen Sie sanft mit dem Kind
  5. Folgen Sie dem Blick des Kindes, wenn es wegschaut
  6. Versuchen Sie, den Blickkontakt wieder herzustellen
  7. Beenden Sie, wenn das Kind Ermüdung zeigt

2 Versteckspiele (Guck-Guck)

Klassische Spiele, die Aufmerksamkeit und Erwartung fördern.

  1. Etablieren Sie Blickkontakt mit dem Kind
  2. Bedecken Sie Ihr Gesicht kurz mit den Händen oder einem Tuch
  3. Erscheinen Sie wieder mit "Guck-Guck!"
  4. Beobachten Sie die Reaktion des Kindes (Erwartung, Freude)
  5. Wiederholen Sie das Spiel, variieren Sie das Timing
  6. Lassen Sie das Kind auch Sie "suchen"

3 Komm-und-Geh-Übungen

Trainieren Sie die Orientierung auf die Bezugsperson bei Bewegung.

  1. Verlassen Sie den Raum kurz (wenige Sekunden)
  2. Rufen Sie das Kind beim Namen
  3. Kommen Sie zurück und zeigen Sie Freude
  4. Beobachten Sie, ob das Kind Sie erwartet hat
  5. Verlängern Sie schrittweise die Abwesenheit
  6. Verbalisieren Sie: "Ich komme wieder!"

✅ Beobachtungs-Checkliste

  • ✓ Erkennt die Bezugsperson wieder
  • ✓ Zeigt Interesse, wenn Bezugsperson erscheint
  • ✓ Folgt der Bezugsperson mit den Augen
  • ✓ Reagiert anders auf Bezugsperson als auf Fremde
  • ✓ Sucht aktiv nach der Bezugsperson
  • ✓ Beruhigt sich durch Anwesenheit der Bezugsperson
  • ✓ Zeigt Freude bei Interaktion mit Bezugsperson
  • ✓ Hält Aufmerksamkeit für längere Zeit aufrecht

💡 Tipps zur Förderung

  • Seien Sie präsent und aufmerksam, wenn das Kind Sie anschaut
  • Reagieren Sie prompt und konsistent auf die Aufmerksamkeit des Kindes
  • Verwenden Sie eine lebendige Mimik und melodische Stimme
  • Respektieren Sie, wenn das Kind den Blick abwendet (Pause)
  • Schaffen Sie vorhersehbare Rituale, auf die das Kind sich freuen kann
  • Vermeiden Sie Überstimulation - Qualität vor Quantität
  • Sprechen Sie das Kind häufig mit Namen an
  • Bei Entwicklungsverzögerungen: Frühförderung in Betracht ziehen
